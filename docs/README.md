## 文档维护

- 新术语及业务含义写入根目录词汇表；实现技术和视觉参数分别归属架构记录与设计规范。
- 架构记录说明已接受的选择与真实权衡；改变决策时保留历史并标明替代关系。
- 整体框架保留功能与验收清单，通过链接引用词汇表和架构决策；若含义或取舍冲突，以对应规范文档为准并修正清单。
- 页面功能规格在实现规划时形成；UI 模式和视觉规范确认后再创建设计系统文档。
- 后续 PRD 与工单引用本基线。当前尚未创建 PRD、发布 GitHub Issues 或配置 GitHub 仓库。
