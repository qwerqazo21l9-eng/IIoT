# 核心业务采用模块化 Java 应用，算法采用 Python 服务

已确认，尚未实现。核心业务采用 Java 与 Spring Boot，流式任务采用 Java 与 Flink，算法与分析采用 Python 与 FastAPI，界面采用 React 与 TypeScript；首版模型使用 scikit-learn，实验和模型管理使用 MLflow。

此前考虑由 FastAPI 承担全部业务。为展示复杂业务边界、审批与审计的工程能力，同时利用 Python 的分析与模型生态，选择按职责分工：配置、诊断、审批、实验和报告属于模块化业务应用，算法和流计算独立运行。

此选择增加跨语言契约与部署维护成本。算法服务提供结果与证据，业务应用负责授权和改善执行协调；边缘检测使用本地模型，离线时不依赖中心算法接口。Spring Modulith 仍为候选工具，不代表已选定。
