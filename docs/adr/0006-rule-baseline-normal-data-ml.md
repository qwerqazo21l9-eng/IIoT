# 正常数据模型与规则基线对照，独立实验验证收益

已确认，尚未实现。以规则完成可解释诊断基线，模型主要学习已知正常数据中的产品与动作模式，进行动作中检测与结束后复核；独立评估通过后版本化发布，先一个边缘节点，再推广并支持回滚。

相比直接让模型预测故障源头或以标注微停训练分类器，此选择保持首条业务闭环可解释，并用同一误报目标比较模型是否增加检出能力或降低延迟。规则按产品配置合理阈值，避免故意设置过弱对照；正常耗时范围内的短停顿不预先承诺可检出。

训练、调参和最终测试按独立运行隔离，测试包含新随机种子、未见参数组合、任意工位单独微停及无故障运行。隐藏故障真值不进入诊断输入，多组成对实验匹配条件和工件质量结果。检测结果与改善报告保留模型和数据版本，所有有效性结论限定于实际验证的模拟条件。
