# 本地边缘与 ECS 中心分离，按业务等级验证恢复

已确认，尚未实现。本地电脑运行两条模拟产线和每线一个边缘节点，中心使用阿里云 ECS 按需付费与多节点 Kubernetes；最终验收覆盖中心工作节点故障，不包含控制平面高可用。

相比仅单机部署或要求全部业务持续可用，此方案展示真实跨网络的云边职责，按业务等级分配恢复能力：采集和事件保存优先，查询允许暂时滞后，训练与报告允许暂停恢复。两条边缘线独立断连，但共享宿主机，不能据此宣称物理机器级容错。

边缘在中心断连时继续采集、检测和缓存，目标为完整保存约定数据八小时；容量不足时优先关键事件并标记降级与缺口。中心恢复后并行处理补传与实时数据。节点规格、复制与存储拓扑、预算及恢复时限仍待测算；多节点部署本身不证明存储容错。
