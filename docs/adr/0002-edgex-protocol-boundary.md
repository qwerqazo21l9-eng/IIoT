# 使用 EdgeX 承载配置驱动的工业接入

已确认，尚未实现。采用 EdgeX 与自定义设备、应用扩展，OPC UA 承担完整动作事件链路，Modbus TCP 补充状态或计数信号；同类产线通过版本化设备与信号映射配置接入。

在自建轻量网关、双网关对照和 EdgeX 扩展之间，选择 EdgeX，以复用设备管理边界并集中实现统一事件、持久化缓存和补传。引入平台增加运行资源与集成工作，不自动保证离线时长或不丢数据，相关能力须实验验收。

统一格式保留协议能力差异、设备身份、事件序号、原始时间、质量与配置版本。动作事件仅描述原始事实，微停由诊断推断；自动时间校正保留依据和误差，参考失效时按分析类型降级。具体 SDK、上传协议、校正机制与格式兼容政策仍待实现阶段确定。
