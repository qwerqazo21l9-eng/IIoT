# 设计系统文档：产线诊断工作台

> UI 模式：`spec-driven`（规范驱动 UI）。端：`web-workbench`，桌面优先的 Web 工作台。
> 来源：[Issue #2](https://github.com/qwerqazo21l9-eng/IIoT/issues/2)；页面与业务状态以[父 PRD 的 UI 与设计要求](../prd/first-production-improvement-loop.md#ui-与设计要求)及 [GitHub 父 PRD](https://github.com/qwerqazo21l9-eng/IIoT/issues/1)为准。

## 1. 概览与创意北极星

### 创意北极星：可核对的工业工作台

面向工程师与管理者的重复工作：扫描产出、核对证据、作出决定、比较结果。视觉优先级依次是当前任务、结果与限制、证据和版本。以紧凑的表格、对齐的数字、共享时间轴和清楚的状态文字建立秩序。页面区块采用留白与分隔线组织，避免用大标题或装饰抢占有效工作空间。

白色工作面与灰色结构保持安静，绿色主色用于明确的操作和选中，蓝色用于信息与关联，紫红色用于比较系列。颜色只提供第二层识别；状态必须同时有文字和图标或纹理。界面应让使用者看出数据是否完整、结论是否可靠，以及当前可执行的操作。

本文件只定义共享视觉参数和原语。五个页面的内容、字段顺序、角色权限和状态转移沿用父 PRD，不在此建立第二套页面规格。领域用语沿用 [CONTEXT.md](../../CONTEXT.md)，结果版本和局部失败表达遵循 [ADR-0004](../adr/0004-storage-ownership-versioned-results.md)与 [ADR-0005](../adr/0005-edge-cloud-failure-scope.md)。单端无需 `platforms.md`；当前设计输入无阻塞项。

主色不得铺满页面。辅色与第三色用于比较、链接和标识，不能因色系相似把它们当作业务结论。

### 语义色

| 错误 | `semantic-error` | #B91C1C | 独立红色 |

## 3. 字体

全部采用本机系统字体，不依赖网络字体下载。标题、正文和标签共用 `font-sans`：`system-ui, -apple-system, BlinkMacSystemFont, "Segoe UI", "Microsoft YaHei", "PingFang SC", "Noto Sans CJK SC", sans-serif`。中文在 Windows 优先使用微软雅黑、macOS 使用苹方，其他系统使用可用的中文无衬线回退。

标识符使用 `font-mono`：`ui-monospace, "Cascadia Mono", Consolas, "Liberation Mono", "Microsoft YaHei", monospace`。长标识符可换行并提供完整值，避免省略后失去核对能力。数字使用 `font-variant-numeric: tabular-nums`，所有字号固定，不随视口宽度缩放，字距统一为 0。

| 角色 | 字体 Token | 字号 / 行高 / 字重 | 样例与用途 |
| --- | --- | --- | --- |
| 页面标题 | `font-sans` | 24px / 32px / 600 | 工作记录；页面主标题 |
| 区块标题 | `font-sans` | 18px / 26px / 600 | 记录详情；无框区块 |
| 紧凑标题 | `font-sans` | 16px / 24px / 600 | 详情侧栏与弹窗 |
| 正文 | `font-sans` | 14px / 22px / 400 | 说明、导航、表格内容 |
| 标签 | `font-sans` | 13px / 20px / 500 | 字段名、表头、状态文字 |
| 元信息 | `font-sans` | 12px / 18px / 400 | 时间、版本和补充说明 |
| 指标值 | `font-sans` | 28px / 36px / 600 | 123.4；主要数值 |
| 标识符 | `font-mono` | 12px / 20px / 400 | EVT-000123；可核对编号 |

一个区块内只保留一个主要视觉重心。数字单位放在相邻的标签层级，限制说明紧邻数字而非藏入 Tooltip。系统字体在不同操作系统上的细微差异可接受，但不得导致控件尺寸随文字变化。

## 4. 层级与深度

静态内容无阴影，层级通过字体、间距、表面和细分隔表达。公共栏与导航在内容层之上，侧栏和弹窗在导航之上，Tooltip 在浮层之上；建议 z-index 依次为 0、20、40、60，只建立必要的堆叠上下文。

浮层使用 6px 圆角；阴影 Token `shadow-overlay` 为 `0 8px 24px rgba(24, 24, 27, 0.16)`，并用 `border-subtle` 定义边界。遮罩 Token `overlay-scrim` 为 `rgba(24, 24, 27, 0.4)`，其混合值随底层变化，不作为固定表面色。

| Token | 基准色 | 不透明度 | 预计算 HEX | 用途 |
| --- | --- | --- | --- | --- |
| `primary-tint-8` | #047857 | 8% | #EBF4F2 | 导航与列表选中、成功浅底 |
| `primary-tint-12` | #047857 | 12% | #E1EFEB | 选中后悬停 |

| `neutral-tint-8` | #18181B | 8% | #EDEDED | 中性按下态 |

焦点统一使用 2px `focus-ring` 实线外圈，外偏移 2px，不仅依赖浅色叠底。选中态不取代焦点态；二者可同时存在。

## 5. 组件

本章定义通用原语，其具体字段、业务标签和页面排列由父 PRD 指定。空间采用 4px 基准，常用间距为 4 / 8 / 12 / 16 / 24 / 32px；圆角不超过 6px。

### 5.1 按钮与交互

标准高度 36px、左右内边距 12px、圆角 4px；标签 14px / 22px、字重 500。主动作允许图标加文字；纯工具动作使用图标按钮。危险操作使用清晰动作文字和必要的确认，不凭红色推断其效果。

| 变体 | 背景 / 文字 | 悬停背景 | 按下背景 |
| --- | --- | --- | --- |
| 主 | `primary-700` / `text-inverse` | `primary-800` | `primary-900` |
| 次 | `surface-subtle` / `text-primary` | `neutral-200` | `neutral-300` |
| 描边 | `surface-work` / `text-primary`，1px `border-control` | `neutral-tint-4` | `neutral-tint-8` |
| 文字 | 透明 / `secondary-700` | `neutral-tint-4` | `neutral-tint-8` |
| 反色 | `surface-work` / `neutral-800`，用于深色面 | `neutral-100` | `neutral-200` |

禁用时背景 `surface-subtle`、文字 `text-secondary`，停用事件并在附近说明原因；不能只降低透明度。提交中保持宽度、用 16px spinner 替换图标，保留动作文字，阻止重复提交。失败后恢复可操作并保留输入。

### 5.2 输入与表单、数值输入

单行控件高度 36px、内边距 8px 12px、圆角 4px，白底、1px `border-control`。标签置于上方，间隔 4px；字段之间 16px。聚焦使用统一焦点圈；错误边框和错误文字引用 `semantic-error`，说明位于字段下方并通过 `aria-describedby` 关联。必填同时用文字或语义属性表达。只读字段使用 `surface-subtle` 并保持文字可选择，不等同禁用。

选项集用原生或可访问的选择菜单，二元值用复选框或开关，模式用分段控件。数值用输入或步进器，按钮命中区域最小 36px，窄屏 44px；单位紧邻字段，不作为占位符。范围、整数要求和精度来自接口契约；错误数值保留供修改，不静默截断或夹到边界。长整数标识保留原字符串精度，不转换成有损浮点数。

### 5.3 卡片容器与列表行

卡片仅用于独立重复项目或真正需要框定的工具：`surface-work`、1px `border-subtle`、6px 圆角、16px 内边距、无阴影。禁止把页面区块当卡片，也禁止卡片内再嵌卡片。

列表行最小高 44px，内容可换行增长，左右内边距 12px、上下 10px，以 `border-subtle` 分隔；悬停 `neutral-tint-4`、选中 `primary-tint-8`，选中后悬停 `primary-tint-12`。支持明确链接和键盘焦点，不能只有整行鼠标点击。

### 5.4 导航与布局

公共栏高 56px，导航宽 208px，内容默认内边距 24px，与 PRD 公共布局一致。公共栏和导航使用 `surface-work`、`border-subtle` 边界；内容为无框工作面。导航项高 40px、图标 18px、图标与文字间隔 8px，当前项使用 `primary-tint-8`、`primary-700` 和左侧 3px 标记，并设置 `aria-current`。页面标题与操作栏允许换行。

视口小于 768px 时，导航收进菜单，内容单列、内边距 16px。公共栏名称可换行但不得覆盖菜单；必要时栏高从 56px 增长，内容偏移同步更新。表格、拓扑和时间轴只在自己的区域滚动，不让整页横向溢出。布局子项设置 `min-width: 0`，内容容器不得用固定最小宽度阻塞窄屏。

### 5.5 角色菜单

触发器为文字加下拉图标，高度 36px；菜单宽度至少 200px、最多 `calc(100vw - 32px)`，白底、6px 圆角、浮层阴影。条目高至少 40px，当前选择同时显示勾选图标和文字。支持键盘方向键、Enter 和 Escape；关闭后焦点返回触发器。演示身份性质需可见，权限说明紧邻受限动作。菜单本身不定义或授予权限。

### 5.6 筛选与搜索框

筛选控件横向对齐、间隔 12px，可自然换行；选中条件可见，清除动作可访问，返回列表保留条件与位置。时间选择必须明确时区与范围，校验提示使用输入错误规范。刷新为图标按钮，保留已有内容并显示刷新状态。

本期无全局搜索，跳过全局搜索框及其下拉结果，不增设搜索入口。后续搜索需由需求明确后再补充规范。

### 5.7 指标与结果对比

指标为无框数字组，标签、值与单位、统计范围、更新时间、版本及限制说明按文本层级呈现。数字使用固定字级和等宽数字；空间不足时组内换行、组间转单列，不缩小字号。未知值使用可见的缺失说明，不以零代替。

结果对比采用共享行标签、成对数值列和变化列，各数值右对齐，单位与精度一致。使用 `secondary-700` 与 `tertiary-700` 区分两个系列，同时显示系列名和不同线型或形状。增减用带符号数字和文字，不靠颜色断言好坏。不可计算或不满足评价条件时显示原因，限制说明位于结果附近；部分结果不冒充已完成汇总。

### 5.8 状态徽章与拓扑状态

徽章是非按钮内联标签：13px / 20px、字重 500、上下 2px 左右 6px、圆角 4px，图标 14px、间隔 4px。通用样例“信息”：`info-tint-8` 背景、`semantic-info` 文字与信息图标。其他提示引用 §2 语义色和 §4 浅底。长标签允许换行，不用固定高度裁切。

拓扑状态节点采用最小宽 120px、内边距 12px的紧凑对象标识，名称与状态标签分行；连接线为 2px `neutral-600`，箭头明确方向。选中节点用焦点圈和选中底，悬停不改变尺寸。空间不足时保持顺序并局部滚动。颜色、文字及图标或纹理共同区分状态，未知观测用断续纹理与显式说明；不得将节点标记解释为已确认的原因。

### 5.9 表格

表头最小高 36px、`surface-subtle` 背景、13px 字重 500；数据行沿用列表行。文本左对齐，数字右对齐，时间与标识符保持可核对；字段顺序由 PRD 指定。表格使用原生表格语义和关联表头，排序按钮显示方向及可访问状态。

数据格内边距 10px 12px，长文本换行，标识符可使用 `overflow-wrap: anywhere`。自身滚动容器可聚焦并有名称；粘性表头不遮挡焦点。分页位于表格之后，显示当前范围，翻页过程中保留区域尺寸。不得截断关键结论、单位或操作标签。

### 5.10 时间线

时间轴标签 12px，每行最小高 40px，片段高 20px；所有行使用相同时间刻度与缩放。片段按类别配合标签和纹理表达，短于可辨宽度的片段显示最小 4px 标记，详情保留真实持续时间，不能把显示宽度当成实际时长。

缩放和重置用带 Tooltip 的图标按钮。选中片段有 2px `focus-ring`，通过键盘可到达并在相邻证据区显示详情；不能仅在悬停时提供信息。为视觉时间轴提供同范围的可访问片段列表。无观测区间使用显式缺口纹理，不连接为连续观测。

### 5.11 证据列表

使用列表行与标签-值原语，元信息 12px、正文 14px。每条来源提供可选择的标识与可访问链接，长来源换行；质量和可信度紧邻内容，支持与排除说明保持相同可读性。展开按钮显示展开状态；收起不丢失选择和焦点。原始值与推断文字明确区分，不用颜色暗示证据已经证实结论。

### 5.12 表单侧栏

侧栏为对话框式浮层，桌面宽 440px、最大 `calc(100vw - 32px)`，内容内边距 24px；窄屏全宽，内边距 16px。头部、滚动正文与操作尾部分区，尾部不得盖住最后一个字段。表单字段沿用 §5.2。

打开后焦点进入标题或首个字段，限制焦点在当前模态内，背景设为不可交互；关闭后返回触发器。关闭按钮带可访问名称。未提交编辑关闭时保留草稿或确认放弃，提交失败保留内容，成功后按真实响应转入只读状态。不得通过重新打开侧栏绕过只读限制。

### 5.13 审批意见与冲突提示

意见使用多行文本原语，最小高 96px，可纵向扩展；标签、必填条件和就地错误沿用表单规范。历史记录使用只读列表行，操作者、时间和原文意见清晰可辨，不用弹出通知代替可追溯记录。

冲突提示使用 `warning-tint-8` 背景、`semantic-warning` 图标与文字，内边距 12px，置于相关操作附近并通过 live region 通知。提示应说明记录已变化，提供刷新操作；冲突期间停用旧版本操作。刷新后显示服务端当前记录，已有决定不得覆盖，未成功提交的文本保留但不得自动再次提交。

### 5.14 进度

每个并列任务单独显示名称、阶段、进度和更新时间；进度条高 6px、圆角 3px，轨道 `neutral-200`、填充 `secondary-700`。已知比例使用 `progress` 语义，未知比例只显示阶段和活动指示，不捏造百分比。显示完成、失败和重试记录时沿用实际响应，并保留过去尝试。

轮询更新不改变容器尺寸或抢占焦点。阶段变化可使用礼貌的 live region，频繁百分比变化不逐条朗读。失败展示阶段和可执行的重试入口，完成进度不等同于结果可评价。

### 5.15 Loading 与骨架

首次加载使用 `neutral-200` 的静态骨架，文字骨架高 14px、圆角 3px，数字骨架高 36px，行骨架最小高 44px；沿用实际内容占位尺寸。加载区域设置 `aria-busy` 并提供一个可访问加载标签，骨架本身对辅助技术隐藏。

刷新保留数据和区域高度，在操作附近显示 16px spinner 与更新时间；旧数据未更新时明确标记。spinner 动画周期约 1s，减少动态效果偏好下改用静态加载图标和文字，禁止闪烁骨架。

### 5.16 空态与局部错误

空态用 24px 中性图标、14px 主说明、12px 次说明以及可选文字或次按钮，位于对应内容区域。按 PRD 区分尚无数据、筛选无结果和暂无记录，并提供适用的刷新、清除筛选等操作；不得把请求失败显示为空列表。

局部错误使用 `error-tint-8`、`semantic-error` 和警示图标，说明失败范围并提供重试；其余可用区块继续显示。存在旧值时保留并显示未更新标记。参数错误回到字段，权限限制提供可见原因，记录冲突使用 §5.13；业务不确定性展示原有结论及依据，不套用系统失败提示。短暂通知可以补充，但不能成为唯一错误反馈。

## 6. 宜忌

### 应当

- 保持工业工作台的信息密度：14px 正文、紧凑行与无框区块，关键数值、证据和限制在同一区域可核对。
- 用文字加视觉标记表达语义状态；区别观测缺失、无法判定、无法评价和系统错误，未知数据不填零。
- 保持公共框架尺寸稳定，宽屏充分利用空间，窄屏单列、局部滚动；在 320px、768px 和 1440px 视口及 200% 缩放下检查可读性、操作与焦点。
- 正文和标签对比度至少 4.5:1，大字号至少 3:1，交互边界和焦点至少 3:1；浅色分隔线仅用于非必要装饰边界。Token 组合或新颜色上线前验证对比度。
- 所有操作支持键盘，焦点清晰且不被固定栏遮挡；输入有标签，错误有关联说明，模态正确管理焦点，动态图形有文本或列表替代。
- 桌面目标最小 36px、触屏最小 44px；工具按钮使用 Lucide 图标与可访问名称，陌生图标同时提供悬停和焦点 Tooltip。
- 表格与指标使用等宽数字、明确单位和完整来源；保留版本、时区、更新时间和限制的可读性。
- 页面字段、角色限制和状态转移始终遵循父 PRD；实现原语时检查默认、加载、空、错误、禁用、提交及业务不确定性。

### 禁止

- 将功能区整体卡片化、嵌套卡片，或用营销式大标题、装饰图片、渐变光斑占用工作空间。
- 只用红绿区分状态，以颜色代替结论，或将未知、缺失与无错误混淆。
- 为通过视觉检查改变业务字段、补造数据、伪造进度或省略结果限制。
- 只依靠禁用按钮表达授权，或把演示角色菜单称为正式认证。
- 用纯悬停承载必读证据，用不可访问的整行点击代替链接，或刷新时清空已有输入。
- 随视口宽度缩放字体、使用负字距、截断关键文字，或让按钮、数字和加载状态改变固定控件尺寸。
