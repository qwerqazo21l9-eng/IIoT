# I03：贯通正常生产到良品 JPH 查询

发布链接：[GitHub Issue](https://github.com/qwerqazo21l9-eng/IIoT/issues/4)。

## 类型与状态

类型：AFK。拟发布标签：`ready-for-agent`。

## PRD 绑定

父 PRD：[首个产线诊断与改善闭环](https://github.com/qwerqazo21l9-eng/IIoT/issues/1)。
覆盖的用户故事：US-1、US-12、US-13、US-15（首条服务路径）。

## 构建内容

从空项目建立最小可运行服务链路：确定性四工位模拟器经真实 OPC UA / EdgeX 投递 Kafka，Java Flink 计算出口良品与基本状态，持久化 PostgreSQL，并通过 Spring Boot 查询真实 JPH。一次命令式演示可得到可核验结果；生产异常与完整 UI 由后续切片扩展。

## UI 模式

headless（本工单交付服务/API/验收路径；父 PRD 仍为 spec-driven）。

## PRD 必读

1. 父 PRD「实现决策」：**首期模块边界**、**模拟产线与真值隔离**、**统一事件契约**、**指标与结果版本**、**工作台服务接口**、**本地演示交付**。
2. 父 PRD「测试决策」：**模拟产线事件输入测试边界**、**EdgeX 与接入统一事件测试边界**、**Kafka 与 Flink 计算输出测试边界**。
3. 父 PRD「用户故事」：US-1、US-12、US-13、US-15（首条服务路径）。

Seam：模拟器输入 → OPC UA / EdgeX → Kafka / Flink 输出 → HTTP 指标查询。。
接口唯一权威来源：上述实现决策及 ADR；行为依据：上述测试决策及本工单验收标准。

## 验收标准

- [ ] 同种子运行具有稳定工件身份、有限缓冲、产品批次、换型和质量事实，诊断消费流不含隐藏故障真值。（PRD 依据：`PRD 实现决策 › 模拟产线与真值隔离`；`PRD 测试决策 › 模拟产线事件输入测试边界`）
- [ ] 至少一条自动集成路径经过实际 OPC UA 与 EdgeX，统一身份、序号、原始时间、质量和配置版本可查。（PRD 依据：`PRD 实现决策 › 统一事件契约`；`PRD 测试决策 › EdgeX 与接入统一事件测试边界`）
- [ ] 实际 Kafka/Flink 输出及 HTTP 查询的出口良品数、JPH、期末在制品与独立核算相符，预热、区间边界和零时长处理正确。（PRD 依据：`PRD 实现决策 › 指标与结果版本`；`PRD 测试决策 › Kafka 与 Flink 计算输出测试边界`；`用户故事 US-1`）
- [ ] 启动入口检查就绪状态，未就绪明确失败；正常运行的配置、种子和结果版本可复现。（PRD 依据：`PRD 实现决策 › 本地演示交付`；`用户故事 US-15`）
